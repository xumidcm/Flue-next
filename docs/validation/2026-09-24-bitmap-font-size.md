# HSC 位图字体字号回归修复

## 复现与根因

样本：`洛明流萤改3.watch`，SHA-256：
`20b2e6e0eef68785926e2987b9710b99de0d0bf1eae4e687c17e90474d01374c`。

包的 description 包含 `Generated by HSC watchface downloader`。Flue 因此先取
`max(text_size, height, info.size)`，再用 `1.6 * size / info.size` 缩放图集。
此前引入标准 1.6 倍率时保留了旧 HSC 补偿，导致重复放大。

对照本地 WFTools 提交 `933a31937b5adaa879f838ea100938b15168edb6`：

- Android `WmPreview.kt:1491–1507` 与桌面 `WmLayerRender.kt:522–538` 均直接使用 `text_size`。
- `WmPreviewGeometry.kt:132–145` 使用相同规则测量。
- `info.size` 为缩放分母，缺失时退回 `lineHeight`；`anim_scale_x/y` 是额外百分比。
- 没有根据包的 HSC 来源、图层 `height` 或字体原始字号抬高目标字号。

样本在 512 设计空间内的字形高度（含动画百分比，不含透明留白和倾斜）：

| 图层 | text_size | height | info.size | 修复前 | 对齐上游后 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 小时 | 126 | 184 | 92 | 267.904 | 183.456 |
| 星期 | 59 | 84 | 46 | 134.4 | 94.4 |
| 分钟 | 112 | 161 | 92 | 257.6 | 179.2 |
| 电量 | 59 | 85 | 46 | 144.16 | 100.064 |

## 修改

`drawText` 直接把求值后的 `text_size` 传给位图绘制，移除旧的
`watchBitmapTextDesignSize` 和仅供该分支使用的 HSC 标记。
保留标准 1.6 倍率、动画百分比、对齐、字形偏移和图集采样逻辑。

用 `WatchBitmapTextRenderingTest` 替换原先要求 HSC 放大的契约测试。
测试使用样本的字形尺寸和不含原作者素材的纯色图集，经过实际解析、加载、
`renderFaceBitmap` 和像素扫描，验证四类文字尺寸、中心锚点、字号表达式、
动画缩放，以及修改包来源说明不会改变结果。
