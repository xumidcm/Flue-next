# 安装复杂表盘后其他表盘加载变慢：验证记录

## 已确认的路径与修复

- `LauncherViewModel.refreshWatchFaces(force = true)` 原来在调用线程递归检查所有安装目录的时间戳；返回桌面时会阻塞主线程。检查已移入 `Dispatchers.IO`，仅在扫描成功发布后更新扫描时间基线。
- `WatchmakerWatchFaceStorage.scanWithDiagnostics` 原来每次为所有已安装表盘构建完整 XML DOM 和图层模型。现在缓存名称、格式、图层数、作者等列表元数据，跨扫描和进程重启复用。
- 缓存位于应用缓存目录，每个 XML 路径一个条目。校验实际 XML 内容的 SHA-256，以识别相同长度、相同修改时间的编辑；原始 XML 和缓存读取均限制大小。
- 缓存失效时仍通过原有安全 XML 解析器校验；损坏缓存可重建，缓存不可写不会隐藏有效表盘。预览路径和安装顺序仍来自当前安装目录。
