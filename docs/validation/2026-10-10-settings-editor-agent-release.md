## 2. 行为实现与交付范围

### 全部设置页统一动效与返回
- 引入通用可折叠标题脚手架 `CollapsibleHeaderScaffold`，支持标题与返回按钮在向上滚动时连续平滑缩小并固定在左上角，带有向下渐隐阴影与圆屏内边距自适应。
- 普通设置与 Agent 多级设置共用折叠规范，紧凑态字号 18sp，返回按钮保持至少 48dp 无障碍点击靶心。
- Agent 设置全面重构为多级页面栈状态驱动，根据当前路由和服务商/工作区 key 保存并恢复滚动偏好。
- 移除 `SettingsActivity` 的 `singleTask` 启动模式；从表盘编辑器进入设置后，按下返回能直接回到原有编辑器实例，完整保留画布与会话状态。
- 统一返回优先级为：上层全屏/Sheet 弹窗 → 当前子设置页 → Agent 根页 → 原宿主界面。保存、导入与测试连接轻量操作切换为系统 Toast 提示。

### 表盘选择、编辑器与应用启动
- 表盘卡片选择器底部圆点精确同步为“当前序号 / 总数”；长名称双向跑马灯边缘增加水平渐隐遮罩。
- 表盘编辑器顶部入口标签由“AI生成”精简规范为“AI”，多语言（en/ja/zh）资源同步更新。
- 顶部快捷操作栏采用独立横向滚动容器与 36dp 紧凑按钮尺寸，适配窄屏与圆屏，不与画布手势冲突。
- 区分编辑态与运行播放态：播放时解除动图/序列帧限速，移除边界控制柄并向底层 `stageView` 完全穿透触摸事件，支持原生长按与 Lua 点击交互；暂停时无缝恢复编辑选择。
- `LauncherViewModel` 移除 1.5 秒硬超时返回限制，启动应用时平稳保持 `ScreenState.App`，仅在真实退入后台又重新返回时触发入场过渡动画。

### Agent 工作区、工具与模型能力
- 工具调度异步化与线程解耦：长耗时命令与文件 IO 统一由协程分发至 `Dispatchers.IO` 执行，消除主线程卡顿；支持超时或主动离开时的受控取消。
- 工作区元数据读取与容量遍历解耦，防止因深层容器文件变动或权限异常导致工作区从列表消失。
- 表盘镜像基于 `watchScope` 实现隔离目录与解绑操作，支持直接读取当前草稿资源，无需预装 Bash。
- 遵循 SAF 规范解析并导入真实文件名，适配 Android 8.1–11 文档提供方。
- 新增免 Bash 原生工具链：`read_file`、`list_archive`、`extract_archive`、`crop_image`，内置于工具契约调度中心。
- 系统提示词硬性注入 512×512 画布尺寸与 H.264 编码约束。
- 历史会话列表自动过滤未发言的空会话草稿；修正多厂商 Token 累计与嵌套 usage 统计。

### 旧版 Android 列表模糊与柔和启动动画
- Android 8.1–11 接入 BlurView 3.2.0 兼容路径，实现列表由模糊变清晰转场。
- “柔和”应用启动曲线刚度调整为 428.16（放慢约 25%），时长匹配至 450ms / 交接 140ms。
- 旧系统列表宿主使用四倍降采样的清晰/模糊复合位图：内容或滚动变化时重新捕获，动画半径变化只更新复合权重；RenderScript 输入/输出 Allocation 和位图复用，避免每个 VSYNC 重复执行完整模糊。
- 转场期间列表启用硬件栅格缓存，父层缩放不再重放每个图标和阴影；复合结果只由覆盖层绘制一次，避免清晰列表与模糊副本重叠。
- Android 8.1–11 在 PixelCopy/预制帧迟到时使用转场开始前的真实清晰表盘显示列表做同几何九宫格回填，缓存就绪后再切换到真实帧；不使用市场缩略图或过期画面。
