# WatchMaker 运行时兼容与全局脚本编辑设计

日期：2026-08-12
状态：已由用户确认交互方向，待书面规格复核

## 目标

修复真实 WatchMaker 表盘在 Flue 中的文字、点击、Lua 状态、表达式、动态颜色、文字圆环和字体尺寸兼容问题，并为表盘编辑器增加安全、可撤销的全局脚本编辑能力。

本次行为以 CloX 为运行时基准，并参考 watchmaker-definition 的格式说明；CloX 未覆盖或近期修复落后时，以 wftools 最新 Git 版本的编辑器预览实现补充验证。实现必须位于共享兼容层，不对单个表盘名称、作者或文件哈希写特判。

## 已确认样本与预期

### Vibe Coder

- WatchMaker 导出器用长连续空格表达的换行仍需恢复为真实换行。
- `alignment="cc"` 继续表示整个多行文字块以原坐标为中心锚定。
- 块内各行共享同一左边缘，不能按各自行宽分别居中。
- TTF 与 BMFont 两条绘制路径采用相同的块内对齐语义。

### 2048 Game

- `rounded` 图层上的 `script:move(...)`、`script:undo_step()` 和 `script:arm_reset()` 必须可点击。
- 点击区域按圆角图层的动态宽高和当前画布变换登记。
- 点击脚本执行后，Lua 全局状态立即参与同一表盘后续帧的文字、颜色、字号和透明度求值。
- 真实 2048 脚本所需的 Lua 表、多个返回值、`table.concat`、`string.sub` 和 `tonumber(value, 36)` 均需回归覆盖。

### Line Graph Demo

- `var_s_t1...var_s_t5`、`var_s_v1...var_s_v5` 等已由脚本声明的变量，如果当前值为 Lua `nil`，文字结果为空字符串。
- 已声明变量的 `nil` 不得被当成“Lua 没处理”，也不得回退为普通模板并把 `var_s_t4` 等源码绘制出来。
- 真正的 Lua 编译或运行失败仍保留可诊断失败语义，不能与合法 `nil` 混淆。

### 混合表达式与 `{bc}`

- 支持表达式结果与普通模板相邻，例如：

  ```text
  ((((({ssc}~=false)) and ({ssc}) or (0)))) {sstr}
  ```

- 解析器需要把可求值的前缀表达式与后续文本或 `{tag}` 模板组合，不能把整串强行当作一个 Lua 表达式。
- `{bc}` 保持 WatchMaker/CloX 语义：充电为 `1`，未充电为 `0`；在纯模板、纯表达式和混合文本中都必须解析，不回显源码。
- 分段解析必须有既有限额保护，不能引入无界回溯或每帧重复解析。

### 精准时图

- `text_ring` 按 `ring_type` 生成实际标签集合。
- `show_every` 控制显示步长，`hide_text` 排除指定数字或一基位置。
- 环形标签使用 CloX 的一基位置规则，使末项落在十二点方向。
- `radius`、`opacity`、`x`、`y` 等 Lua 动态属性每帧读取最新脚本状态。
- 图层携带 `tap_action` 时登记点击区域，点击后折叠、展开以及分钟/秒钟精度变化必须跟随 Lua 动画状态。

### Nexus 2.2

- 点击网格后执行 `nexus_tap(...)`，红、绿、蓝、黄四种动态颜色都能显示。
- 合法的六位或八位十六进制颜色字面量优先按颜色解析；`0066e6` 不得被通用文本求值器误当成科学计数法。
- `color="var_col"`、`color="wf_col(0)"` 等动态颜色继续通过实时 Lua 求值。
- `text_size` 等动态字号通过数值上下文求值，并沿用 WatchMaker 的 TTF 设计尺寸倍率；普通原生 WatchMaker 字体不进入 HSC/BMFont 专用放大路径。

## 运行时设计

### 文字布局

在共享文字布局策略中区分“图层锚点对齐”和“多行块内对齐”。普通单行文字保持现有 `alignment` 行为。由真实换行或导出空格恢复出的多行文字，以各行最大宽度确定整个文字块的边界；Vibe Coder 兼容语义下，各行从块的左边缘开始绘制，块整体仍围绕原锚点定位。

TTF 和 BMFont 都使用相同的行列表、块宽和每行起点策略。点击包围盒按最终各行矩形合并，避免布局与点击区域分叉。

### 点击目标

提取共享的矩形点击目标登记策略，由 `shape`、`rounded`、普通文字、位图文字、图片和 `text_ring` 复用。只登记显式非空的 `tap_action` 或 `action`，边界经过当前 Canvas 矩阵映射到视图坐标。

透明的动作热区仍可点击；没有动作的上层图层不会遮挡下层动作图层。命中后沿用现有 Lua 沙箱和完整重绘入口。

### Lua 求值结果

Lua 属性求值返回内部三态结果：

- 不引用表盘脚本状态；
- 已引用并成功求值，结果可以是值或合法 `nil`；
- 编译、限额或执行失败。

文字属性遇到“成功且为 nil”时输出空字符串。数值、布尔和颜色属性根据各自上下文使用既有回退值。只有“不引用脚本状态”才进入普通 WatchMaker 表达式求值；失败保留错误诊断并采用安全回退，不回显已声明变量源码。

Lua 全局或点击片段结束后继续刷新动态变量名集合；表内原地写入仍通过每帧实时求值反映，不把表值错误转成文本。

### 表达式和颜色上下文

文本求值先识别完整表达式；失败时再尝试有边界的“表达式前缀 + 模板后缀”分段。候选分割点只来自顶层括号闭合后的文本边界，忽略引号与嵌套内部位置。前缀必须完整编译成功，后缀按普通标签模板插值，结果按原顺序连接。

纯标签、普通文案、带空格文字和零填充数字保持现有模板语义。分段结果进入既有长度上限和编译缓存。

颜色解析使用独立入口：先识别 `#` 可选的合法 6/8 位十六进制常量，再尝试 Lua 或 WatchMaker 动态表达式，最后交给 Android 颜色解析。这样既保护 `0066e6`，也保留脚本动态颜色。

### 文字圆环

增加纯函数策略负责：

- 将 `ring_type` 映射为数字、罗马数字、星期或月份标签；
- 使用 `show_every` 和 `hide_text` 过滤标签；
- 计算 CloX 一基角度；
- 计算圆环整体点击边界。

绘制函数只消费策略结果并应用动态半径、字号、颜色和透明度。测试直接覆盖纯函数，View 级策略测试覆盖点击登记要求。

## 编辑器全局脚本设计

### 入口和界面

在编辑器“全局”区域增加“编辑脚本”按钮。点击后打开全屏脚本编辑界面，包含：

- 标题“全局脚本”；
- 等宽、多行、可滚动文本输入；
- 取消和保存操作；
- 当前 UTF-8 字节数及 256 KiB 上限提示；
- 校验失败时的明确错误信息。

编辑时不实时写文件。取消丢弃本次输入；保存成功后关闭界面并刷新编辑器预览。

### 会话、历史和保存

`WatchEditorSession` 提供读取及更新全局脚本的 UI 无关接口，路径固定为 `scripts/script.txt`，并继续使用现有安全相对路径校验。

编辑器历史状态加入脚本内容摘要及受控资源状态，使脚本保存成为一个撤销点；撤销、重做、脏状态、保存当前版本、另存为和导出都包含脚本变化。脚本不作为普通图片资源暴露在资源列表中。

保存规则：

- 非空脚本按 UTF-8 写入，父目录不存在时自动创建；
- UTF-8 大小超过 256 KiB 时拒绝保存；
- 内容全部清空并保存时，直接删除 `scripts/script.txt`；
- 删除脚本后若 `scripts` 目录为空，可保留空目录，不执行额外目录清理；
- 文件写入失败时恢复操作前状态，不产生撤销记录。

预览刷新复用编辑会话现有 revision/资源变化机制，使 Lua runtime 以新脚本重新创建，旧的脚本全局状态不能泄漏到新版本。

## 安全与性能

- 全局脚本继续运行于现有 CloX 对齐沙箱：无 Java、文件系统、包加载器、调试接口或系统命令能力。
- 保留脚本、片段和表达式的字节、字符、指令与缓存数量上限。
- 不从表盘名称、作者或样本哈希决定行为。
- 不使用 ADB，不修改依赖版本，不清理 Gradle 缓存或 `.gradle-fresh/`。
- 上游仓库只用 Git 获取并记录对照提交，不复制不相关应用代码。

## 测试与验收

测试遵循红—绿—重构，每项在生产代码修改前先观察到正确失败：

1. 空格恢复多行文字的块内左对齐，覆盖 TTF 与 BMFont。
2. `rounded` 和 `text_ring` 动作层点击区域策略。
3. 真实 2048 Lua 脚本按钮调用后棋盘和分数状态变化。
4. 已声明 Lua 变量为 nil 时文字为空，Lua 失败与 nil 可区分。
5. 混合表达式示例、`{bc}` 的模板/表达式/混合三种形式。
6. `0066e6` 常量和 Lua 动态颜色都正确解析。
7. `text_ring` 的标签集、步长、隐藏项和一基位置。
8. 精准时图点击后动态半径、位置、透明度与标签密度变化。
9. Nexus 脚本点击后四种颜色均可由实时求值器解析。
10. 脚本读取、创建、覆盖、超限、清空删除、撤销/重做、脏状态、导出和预览 revision。

完成后依次执行：

```powershell
.\gradlew.bat :app:testDebugUnitTest --no-daemon --console=plain
.\gradlew.bat :app:assembleRelease --no-daemon --console=plain
```

Release APK 使用 `local.properties` 指向的 Android SDK 中 `apksigner` 验证签名，并记录构建耗时、APK 大小和 SHA-256。最后只暂存已审查源代码、测试、资源和规格文件，排除 `.gradle-fresh/` 及诊断垃圾，创建如实描述改动的简体中文提交。

## 非目标

- 不改写或重新打包用户提供的表盘样本。
- 不为脚本编辑器增加语法高亮、自动补全、运行控制台或在线下载。
- 不扩大 Lua 沙箱权限。
- 不修复 wftools 或 CloX 仓库本身。
- 不处理与本批样本无关的 WatchMaker 图层家族重构。
