# 表盘市场导航修复

目标：修复登录被详情遮挡、全部评论遮挡创作者、连续浏览丢失父页面，以及收藏和合集无法原路返回的问题。

## 页面与状态

- 市场首页作为栈底；详情、创作者列表、单个创作者、我的上传与登录、上传、收藏、合集、通知和资料使用同一个导航栈。
- 每次入栈获得独立页面 ID；相邻重复点击不重复入栈，跨页面再次打开相同表盘仍保留独立页面状态。
- 父页面保留组合及滚动、合集选择和评论状态，子页面按栈顺序覆盖。出栈保留现有退场动画，结束后释放页面。
- 只有栈顶页面响应系统返回并显示自己的弹窗。全部评论打开作者或登录时暂时隐藏，返回详情后恢复评论及滚动位置。
- 表盘详情独立加载，下载和安装仍复用市场仓库及已有事务。
- 会话失效时移除需要鉴权的路由，保留公开详情与登录入口，避免留下空白拦截层。
- 详情重新成为当前页面时后台刷新元数据和社交数据；刷新失败时保留已有评论、收藏和合集内容，错误另行显示。

## 验证

- 回归覆盖多层作者与详情往返、收藏与合集来源、评论页面恢复、登录覆盖顺序、上传返回、重复点击与重复访问。
- 验证实际页面容器与导航状态的接线，并运行市场相关测试和 Windows 原生 Release 构建。
- 不使用 ADB；真机触摸、圆屏观感与动画体验仍由设备验收。
